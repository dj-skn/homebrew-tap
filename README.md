# homebrew-tap

Homebrew formulae for [dj-skn](https://github.com/dj-skn)'s tools.

## Usage

```bash
brew install dj-skn/tap/notion-bg
```

Or tap it once and install by bare name afterwards:

```bash
brew tap dj-skn/tap
brew install notion-bg
```

## Formulae

| Formula | Description |
|---|---|
| `notion-bg` | [notion-bg-gen](https://github.com/dj-skn/notion-bg-gen) - mesh-gradient cover images for Notion pages |

## Maintenance

Formulae here are bumped automatically by the source project's release workflow.
That requires a `HOMEBREW_TAP_TOKEN` secret on the source repository, holding a
token with `contents: write` on this one.
